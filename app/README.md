# Yukino Desktop Pet

Windows 透明置顶 Live2D 桌宠，当前发布候选版本为 `v1.4.0-rc3`。程序使用从 Cubism 5.3 工程另行导出的 SDK 5.0 兼容资源；原始 `.cmo3`、`.psd` 和 `.can3` 保存在项目根目录的 `model-source/`。

## 主要功能

- Live2D 待机、眨眼、表情和轻量视线跟随。
- 人物透明像素命中、拖动、缩放、置顶和鼠标穿透。
- 68 条原创日语语音和对应中文字幕。
- 单击、双击、连击、时间、天气、返回、恢复、久坐和随机闲聊触发。
- 事件优先级、家族合并、冷却、安静时间和每日上限。
- 区县级天气定位、30 分钟缓存和失败重试。
- 跟随人物移动与缩放的粉色花朵字幕云。
- 实时振幅口型、嘴部 Part 互斥和非说话状态最大嘴型限制。

## 操作

- 左键拖动：移动桌宠。
- 单击：短暂微笑，并按设置概率尝试点击回应。
- 双击：短暂惊讶，并按设置概率尝试双击回应。
- 快速点击三次以上：尝试连续点击吐槽。
- 滚轮：缩放人物。
- 右键：打开人物侧边的粉白控制面板，可手动点播、报时、查询天气、切换表情及调整设置。按住菜单顶部可手动移动，位置会自动记忆；“恢复侧边”可重新启用自动停靠。
- `Ctrl+Alt+Y`：强制关闭鼠标穿透并重新显示桌宠。

## 主动行为设置

- 主动发言总开关。
- 安静、标准、活跃三档发言频率。
- 全部天气、仅恶劣天气、关闭天气主动提醒。
- 支持跨午夜的自定义安静时间。

手动点播和人物点击回应不受主动发言总开关限制。完整规则见 `../docs/雪乃桌宠_全部互动说话原理手册.txt`。

## 开发启动

```powershell
pnpm install
pnpm start
```

## 构建 Windows 运行版

```powershell
pnpm dist
```

构建产物位于 `release/Yukino Desktop Pet-win32-x64/`。

若常规构建因 GitHub 网络超时而无法下载 Electron，可指定本机缓存：

```powershell
$env:ELECTRON_ZIP_DIR = "<Electron ZIP 缓存目录>"
pnpm dist
```

`scripts/package-windows.mjs` 只排除项目根目录的旧构建产物，不能使用会匹配依赖目录的宽泛 `dist` 过滤规则；否则会误删 Pixi 和 Live2D 引擎的浏览器脚本。

## 目录说明

- `assets/model/`：Live2D 运行资源。
- `assets/voice/dialogues.json`：台词和触发配置。
- `assets/voice/generated/`：正式 WAV 和生成清单。
- `renderer/`：人物渲染、点击、表情、语音和口型。
- `subtitle/`：字幕云界面。
- `trigger-engine.js`：时间、天气、点击、返回和工作触发。
- `behavior-coordinator.js`：事件合并、优先级和过期队列。
- `weather-service.js`：区县解析、天气请求和缓存。

## 第三方与分发注意事项

`vendor/live2dcubismcore.min.js` 是 Live2D Cubism SDK for Web 的专有运行库，使用和分发须遵守 Live2D 许可。角色形象、参考音频和 GPT-SoVITS 权重在公开分发前也需要单独确认授权范围。

## v1.4.0-rc3

- 右键菜单顶部支持按住拖动，可手动改变面板位置。
- 自定义位置写入本地状态，关闭并重新打开后仍保持。
- 增加“恢复侧边”操作，可随时回到跟随人物的自动停靠模式。

## v1.4.0-rc2

- 担心表情固定使用闭合的担忧嘴，避免开口参数导致嘴线不稳定。
- 连点改为第三次点击即时触发，并加入短防抖，避免持续连打迟迟不响应。
- 原生右键长菜单替换为停靠在人物侧边的粉白控制面板。

## v1.4.0-rc1

- 台词扩充至 68 条，新增手动报时、区县级天气和天气情境台词。
- 新增天气缓存、失败重试和天气设置界面。
- 新增主动行为协调层，统一管理时间、天气、返回、久坐、点击和随机事件。
- 新增主动发言开关、三档频率、天气范围和自定义安静时间。
- 语音队列在派发前占用播放槽，避免多音频同时启动。
- 8 个嘴部 Part 每帧互斥，修复多口型重叠。
- 最大嘴型仅允许在实际语音高振幅时出现。
- 修复双击惊讶表情中等嘴型与开口参数不匹配导致的短暂无嘴现象。
- 修复临时点击表情被语音打断后恢复计时丢失的问题。
