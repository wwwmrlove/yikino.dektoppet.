# Yukino Desktop Pet

Windows 透明置顶 Live2D 桌宠，当前发布候选版本为 `v1.4.0-rc4`（2026-09-12）。程序使用从 Cubism 5.3 工程另行导出的 SDK 5.0 兼容资源；原始 `.cmo3`、`.psd` 和 `.can3` 保存在项目根目录的 `model-source/`。

## 主要功能

- Live2D 待机、眨眼、表情和轻量视线跟随。
- 人物透明像素命中、拖动、缩放、置顶和鼠标穿透。
- 68 条原创日语语音和对应中文字幕。
- 单击、双击、连击、时间、天气、返回、恢复、久坐和随机闲聊触发。
- 事件优先级、家族合并、主动／点击独立冷却、安静时间和每日上限。
- 区县级天气定位、地点绑定缓存、复合天气提醒和失败重试。
- 跟随人物移动与缩放的粉色花朵字幕云。
- 实时振幅口型、最终嘴部图像可见性检查；非说话状态禁止最大嘴型。
- 播放超时释放、有限次渲染恢复、单实例和托盘找回入口。

## 操作

- 左键拖动：移动桌宠。
- 单击：短暂微笑，并按设置概率尝试点击回应。
- 双击：短暂惊讶，并按设置概率尝试双击回应。
- 快速点击三次以上：尝试连续点击吐槽。
- 滚轮：缩放人物。
- 右键：打开人物侧边的粉白控制面板，可手动点播、报时、查询天气、切换表情及调整设置。按住菜单顶部可手动移动，位置会自动记忆；“恢复侧边”可重新启用自动停靠。
- `Ctrl+Alt+Y`：强制关闭鼠标穿透并重新显示桌宠。
- 双击系统托盘图标：找回桌宠并关闭鼠标穿透。托盘右键还可打开控制面板、重新载入角色和退出；快捷键被占用时仍可使用。
- 再次启动程序：唤回已有桌宠，不另开一只。小屏幕或显示器变化时会重新限制人物、菜单的位置和尺寸。

## 主动行为设置

- 主动发言总开关。
- 安静、标准、活跃三档发言频率。
- 全部天气、仅恶劣天气、关闭天气主动提醒。
- 支持跨午夜的自定义安静时间。

手动点播和人物点击回应不受主动发言总开关、安静时间及主动次数上限限制。点击采用独立的 8 秒跨类型冷却，同时保留单击／双击／连击的 45／30／20 秒分类冷却；忙碌时最多排队 5 秒，过期只保留此前的表情反馈，不补播迟到吐槽。点击不占主动提醒次数，也不更新主动冷却时间。台词自身的防重复冷却保持不变。

右键选择的表情是本次运行的常驻选择，语音结束和临时点击表情到期后会回到该选择；说话期间手动换表情也会保留。完整规则见 `../docs/雪乃桌宠_全部互动说话原理手册.txt`。

## 开发启动

```powershell
pnpm install
pnpm start
```

## 构建 Windows 运行版

```powershell
pnpm dist
```

构建产物位于 `release/Yukino Desktop Pet-win32-x64/`。

若常规构建因 GitHub 网络超时而无法下载 Electron，可指定本机缓存：

```powershell
$env:ELECTRON_ZIP_DIR = "<Electron ZIP 缓存目录>"
pnpm dist
```

`scripts/package-windows.mjs` 只排除项目根目录的旧构建产物，不能使用会匹配依赖目录的宽泛 `dist` 过滤规则；否则会误删 Pixi 和 Live2D 引擎的浏览器脚本。

## 目录说明

- `assets/model/`：Live2D 运行资源。
- `assets/voice/dialogues.json`：台词和触发配置。
- `assets/voice/generated/`：正式 WAV 和生成清单。
- `renderer/`：人物渲染、点击、表情、语音和口型。
- `subtitle/`：字幕云界面。
- `trigger-engine.js`：时间、天气、点击、返回和工作触发。
- `behavior-coordinator.js`：事件合并、优先级和过期队列。
- `weather-service.js`：区县解析、天气请求和缓存。
- `renderer/mouth-controller.js`：校准口型档位及最终绘制可见性检查。
- `renderer-recovery.js`：渲染启动超时和有限次数恢复。
- `json-store.js`：原子 JSON 写入、有效备份和损坏回退。
- `safe-logging.js`：断开输出管道的容错和文件日志轮换。
- `tests/`：口型、播放协议、队列、天气、设置、窗口布局和日志回归测试。

## 故障恢复与日志

语音派发后 10 秒未收到开始通知会取消并释放播放槽。开始后的完成看门狗采用音频时长加 5 秒，最短 15 秒、最长 180 秒；未知时长使用 60 秒。每句由主进程分配唯一 token，过期回调不会结束后来的语音。

人物渲染准备超时为 20 秒。异常后按 1／2／4 秒退避，连续最多自动重新载入 3 次；失败后可从托盘或控制面板重新载入。稳定运行 60 秒后重置重试计数。恢复期间清理旧队列和字幕，暂停语音派发。

设置采用临时文件原子替换并保留 `.bak` 有效备份，人物／菜单移动保存合并到约 300 毫秒后。日志位于用户数据目录下的 `logs/main.log`，通常为 `%APPDATA%\yukino-desktop-pet\logs\main.log`；达到约 1 MiB 后轮换为 `main.log.previous`。启动终端关闭造成的 `EPIPE`／已销毁输出流不会再因日志输出使程序退出。

## 第三方与分发注意事项

`vendor/live2dcubismcore.min.js` 是 Live2D Cubism SDK for Web 的专有运行库，使用和分发须遵守 Live2D 许可。角色形象、参考音频和 GPT-SoVITS 权重在公开分发前也需要单独确认授权范围。
